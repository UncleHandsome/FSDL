# 🐉 龍・山・水 聚氣綜合模擬器

**「氣乘風則散，界水則止。古人聚之使不散，行之使有止，故謂之風水。」** 
—— 晉・郭璞《葬書》

這是一個基於傳統地理風水「巒頭派」理論，並結合粒子物理引擎開發的**2D/2.5D 風水地理氣場視覺化模擬器**。本工具將無形的「氣」具象化為動態粒子，幫助使用者直觀地觀察地形（龍、砂、水、穴、向）如何影響氣場的流動、聚集與消散。

---

## 🌟 核心功能與視覺化指標

在模擬器中，你可以透過觀察「粒子」的行為來判斷風水吉凶：

*   🟡 **黃色粒子（真氣）：** 來自龍脈的生氣。聚集在明堂且穩定飄動代表「聚氣」。
*   🔴 **紅色粒子（煞氣）：** 遇到不良地形（如破碎砂、反弓水、直沖）或形煞（如天斬煞）時，真氣會質變為具有破壞力的煞氣。
*   🔵 **藍色粒子（水氣/流失）：** 真氣若無擋護受風吹散，或被無情水沖走，將化為虛無洩出。
*   ✨ **金色波紋（淨化）：** 當特殊吉格（如蜂腰化煞、半月池、三叉水）發揮作用時，會產生淨化煞氣的視覺波紋。
*   🔥 **熱力圖 (Heatmap)：** 呈現氣場停蓄的密度分布。顏色越偏紅黃，代表該處聚氣越強。

## 📖 如何用模擬器觀察風水（操作指南）

模擬器的右側面板提供了完整的地理元素控制。建議按照風水學的**「地理五訣」（龍、穴、砂、水、向）**順序來進行觀察與配置：

### 第一步：尋龍（龍勢）
「龍」代表山脈的走勢，是氣的源頭。
*   **吉龍：** 選擇「躍龍」或「迴龍」，觀察氣脈如何生動活潑地蜿蜒而下。
*   **凶龍：** 嘗試切換為「死病」或「破龍」，你會發現氣息微弱，甚至在半途就崩解為煞氣。
*   **平洋龍：** 觀察「平洋（平地）」模式，氣場將由高山潛行轉為平地鋪展，此時極度依賴「水」來界氣。

### 第二步：察砂（左砂、右砂）
「砂」是指主山左右兩側的護衛山丘（青龍與白虎），負責「藏風」。
*   **有情砂：** 將左右砂設為「有情」，開啟「風場」視角，觀察護砂如何像雙臂一樣擋住外部強風，保護明堂內的氣不被吹散。
*   **無砂/逼壓：** 移除護砂（無），真氣會被風吹走（氣乘風則散）；若設為「逼壓」或「抬頭煞」，則會壓迫明堂，產生內部亂流。

### 第三步：觀水（水勢）
「水」負責將龍脈帶來的氣「界止」並聚集在穴前（明堂）。
*   **有情吉水：** 選擇「玉帶」或「九曲」，觀察氣場如何平穩地停蓄在河灣內部。
*   **無情凶水：** 切換至「割腳」、「反弓」或「淋頭」，觀察強烈的水流引力如何將好不容易聚集的真氣無情地扯走或沖散。

### 第四步：點穴（星體、穴形與護從）
「穴」是最終結氣的焦點。
*   **五行生剋：** 嘗試不同的「星體」（金、木、水、火、土）與「穴形」（窩鉗、乳突）搭配。例如：金星結窩穴為吉，若火星結窩則會犯煞。
*   **明堂與太極：** 開啟「明堂」與「太極」開關，觀察真氣如何被引導至太極暈中心並產生螺旋沉澱。
*   **案山與朝山：** 在前方加入「案山」，觀察它如何產生「迴風返氣」的效果，將即將溢出的氣托回穴場。

### 第五步：立向（坐向）
*   **向水 vs 背水：** 點擊「其他」分類中的坐向開關。一般山龍應「向水」，若改為「背水」，你會發現氣場無法與水交融，分數大幅下降。

### 第六步：加入形煞或水口神獸（進階觀察）
*   **水口攔截：** 在水法/水口處加入「羅星」、「華表」或「獅象」，觀察在河流出口處的神獸如何發揮「水壩效應」，將氣強制鎖在明堂。
*   **形煞破壞：** 開啟「天斬煞」、「凹風煞」或使用「手動（點擊畫面放置煞物）」，觀察罡風或銳角如何像刀子一樣切碎真氣。

## 📊 數據面板解讀

在介面右下方，模擬器會即時計算當前地形的風水評分：

1.  **聚氣指數：** 目前成功蓄積在明堂與太極暈內的吉氣總量。
2.  **散氣／煞氣：** 流失或轉變為煞氣的比例。數字越高，代表格局越破敗。
3.  **容量/乘數：**
    *   *容量：* 地形的硬體大小（如是否有明堂、案山、水口交鎖）。
    *   *乘數：* 地形的整體品質（如是否犯煞、龍勢是否健康）。乘數低於 1.0 會嚴重打擊聚氣效果。
4.  **五訣雷達圖：** 直觀顯示目前佈局在「龍、穴、砂、水、向」五個維度的強弱。
5.  **系統判詞：** 根據整體分數給予評價（如：上吉・龍真穴的、大凶・無穴可立），並列出當前犯了哪些煞氣。
